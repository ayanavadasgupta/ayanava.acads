# Ayanava Dasgupta — research website

A fast, accessible, static personal research website ready for GitHub Pages. It has no build step or dependencies.

## Publish on GitHub Pages

1. Create a GitHub repository named `ayanavadasgupta.github.io` (replace `ayanavadasgupta` with your GitHub username) and make it public.
2. Upload every file and folder in this directory to the repository’s top level.
3. On GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.
4. After GitHub finishes publishing, your site will be available at `https://YOUR-USERNAME.github.io`.

For a project repository instead, the site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Update content

- Homepage text and papers: `index.html`
- Full online CV: `cv.html`
- Colours, type and layout: `assets/styles.css`
- Mobile menu and footer year: `assets/site.js`

Paper links, research details, education, awards, and teaching history were transcribed from the supplied CV. Before publishing, proofread the presentation and contact details, especially whenever a paper’s publication status changes.

## Optional additions

- Add a professional headshot and link it in the hero area.
- Create a Google Scholar profile and add it beside LinkedIn in the Contact section.
- If you prefer a downloadable CV, save the online `cv.html` as PDF from its **Print / Save PDF** button, then upload the PDF and add a download link.
